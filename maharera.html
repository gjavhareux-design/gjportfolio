UX Strategy

The Challenge & Solution

MahaRERA exists to protect homebuyers. But the tool designed for transparency was creating friction.

The Friction (Pre-2023)
The legacy system operated in silos. Citizens struggled to find compliance records, while Promoters frequently abandoned the complex quarterly update forms.
  • Fragmented search required users to navigate 4 separate databases.
  • 72% of users struggled to find specific project compliance records.
  • Zero mobile responsiveness alienated a huge user base.
The Blueprint (Redesign)
We completely rebuilt the information architecture around user mental models, bridging the gap between Promoter data input and Citizen data consumption.
  • Implemented a Universal Search Bar as the primary interface.
  • Role-based navigation for Homebuyers, Promoters, and Agents.
  • Fully responsive, GIGW compliant design ensuring accessibility.
